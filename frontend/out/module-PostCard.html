Module: PostCard

Este arquivo contém o componente `PostCard`, responsável por renderizar um post e permitir interações como avaliação por estrelas, seguir autor, abrir comentários e acionar edição/exclusão.

Methods

(inner) PostCard(props) → {JSX.Element}

Componente de cartão (Card) para exibição e interação com posts. Ele gerencia a avaliação do usuário, o seguimento do autor e as interações de edição/exclusão.
Parameters:
Name Type Description
props object As propriedades do componente.
Properties
Name Type Attributes Default Description
post Post O objeto de dados do post a ser exibido.
onMonetizeClick function <optional>
 Callback chamado ao clicar no botão "Apoiar". Recebe o username/name do autor.
onCommentClick function <optional>
 Callback chamado ao clicar no botão "Comentar". Recebe o postId.
onDeleteClick function <optional>
 Callback chamado ao excluir o post. Se fornecido, ele é usado no lugar da ação Redux `deletePost`.
onEditClick function <optional>
 Callback chamado ao clicar no botão "Editar". Recebe o objeto Post.
onSaveEdit function <optional>
 Callback chamado ao salvar a edição. Recebe o postId.
onCancelEdit function <optional>
 Callback chamado ao cancelar a edição.
isEditing boolean <optional>
 false Indica se o post está atualmente no modo de edição.
editText string <optional>
 O texto atual (corpo) da edição.
editTitle string <optional>
 O título atual da edição (para posts de texto/letra).
onEditTextChange function <optional>
 Handler para a mudança do texto do corpo da edição.
onEditTitleChange function <optional>
 Handler para a mudança do texto do título da edição.
isOwnProfile boolean <optional>
 false Indica se o cartão está sendo exibido no perfil do próprio usuário logado (usado para esconder Follow/Support).
