Componente de Proteção de Rota (Guard). Ele verifica o estado de autenticação do usuário através do Redux. Se o usuário NÃO estiver logado (`!currentUser`), ele redireciona o usuário para a página de login (`/login`) usando o componente `Maps` do `react-router-dom`. Se o usuário estiver logado, ele renderiza os componentes filhos (`children`).
